# FAEI — تعي نقعد بالفَيّ

موقع مطعم ومقهى FAEI في كلية الأمير عبدالله بن غازي لتكنولوجيا المعلومات، جامعة البلقاء التطبيقية.
React + Vite + TypeScript على Vercel، والطلب بيوصل على واتساب وعلى لوحة الإدارة `/admin`.

## نفس الموقع لكافيتيريا ثانية

- شو بدنا من الكافيتيريا: [`docs/جيبلي.md`](docs/جيبلي.md)
- كل الخطوات التقنية (الاستضافة، قاعدة البيانات، اللوحة، المنيو، الصور): [`docs/NEW-CAFETERIA.md`](docs/NEW-CAFETERIA.md)
- هوية الكافيتيريا كلها بملف واحد: `src/brand.json`. الأيقونات بتطلع من `scripts/make-icons.py`.

## وين بتعدّل إيش

| بدك تغيّر | وين |
|---|---|
| الأصناف والأسعار والصور، "مش متوفر" | لوحة الإدارة `/admin` ← الأصناف (أو `public/menu.json`) |
| العرض | لوحة الإدارة ← العرض (أو `public/offer.json`) |
| كليك وشيت الطلبات | `public/settings.json` |
| الاسم، الواتساب، الانستغرام، اللوكيشن، الدوام، التوصيل، الألوان، صور المعرض | `src/brand.json` |

## تشغيل على جهازك

```bash
npm install
npm run dev
```

## النشر

المشروع مربوط بـ Vercel: أي تعديل بينرفع على فرع `main` بينزل على الموقع لحاله خلال دقيقة.
الطلبات والحسابات بـ Upstash Redis (من Vercel ← Storage).
